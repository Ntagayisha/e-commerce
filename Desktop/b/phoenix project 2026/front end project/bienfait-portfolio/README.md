# Ntagayisha Bienfait — Portfolio

This is a simple static portfolio scaffold created for Ntagayisha Bienfait.

How to use

1. Open `index.html` in your browser (double-click or right-click -> Open with).
2. Edit the `index.html` content to add real projects, images and links.
3. To make the contact form work, replace the demo handler in `script.js` with a real API endpoint (e.g., `fetch('/api/contact', { method: 'POST', body: JSON.stringify(...) })`).

Files

- `index.html` — main page
- `styles.css` — basic styles
- `script.js` — small client logic for demo contact form
